## 15초 세로 숏폼 추천 구성
1. 0~1초: 검은 화면에 손가락이 위로 쓱 → 피처 그래픽 or 로고 + 쭉이(jjugi_excited) 튀어나옴 (훅: "넘길 때마다 다른 게임")
2. 1~9초: **실제 게임 녹화 클립** 6~8개를 1초씩 빠르게 넘기기(스와이프 전환). 각 클립 위에 PERFECT 도장·좋아요 숫자·콤보 불꽃을 크게
3. 9~12초: 쭉이 성장 5단계가 0.4초 간격으로 자람 + "구독자 1,000 → 나무!" 자막, 색종이
4. 12~15초: 크리에이터 3명 + 쭉이 단체 컷(배경 mint_gradient), 로고 + "저스트스크롤"

## 중요
- 영상의 핵심은 **실제 플레이 화면**이다. 게임에서 녹화 모드(세 손가락 탭 = 튜닝 버튼·디버그 숨김)를 켜고 폰 화면 녹화로 찍는다. 이 폴더 그림은 그 녹화를 꾸미는 재료.
- 햄찌(4번째 채널)는 알파 기능이라 빠져 있음.
- 효과음 일부는 Kenney(CC0). 게임 음악을 영상에 쓰려면 직접 작곡한 최종본으로.
